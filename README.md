# Lab1Web
Студентка: Швидько Крістіна Романівна

Група: КВ-31

Назва лабораторної роботи: Розробка статичного інтерфейсу Web-додатка

Звіт Посилання на звіт:

Мета: ознайомитись із засобами мов HTML5 та CSS3 та навчитись застосовувати бібліотеки Twitter Bootstrap/Tailwind CSS/Material UI щодо швидкої побудови Web-інтерфейсу користувача.

Загальне завдання: розробити статичні Web-сторінки додатку та перевірити коректне їх відображення на екранах різного розміру.

Інструменти розробки: мови HTML5, CSS3, фреймворки Twitter Bootstrap, Material UI (та подібні). (уроки від Tutorial Republic)

Обрана тема:
Платформа для зберігання телефонних номерів «AllContacts».

Опис додатка:
AddContacts — це додаток, який дозволяє легко зберігати номери телефонів та email ваших друзів, колег та сімʼї.

Головна сторінка(Main): Це сторінка, яка містить список всіх збережених Вами контактів (імʼя, прізвище, номер телефону та email). Користувачі можуть додавати нові контакти, видаляти, редагувати та відсортовувати вже існуячі. 

Профіль (Profile): сторінка профілю надає користувачам можливість переглядати та редагувати особисту інформацію, таку як ім'я, прізвище, електронна адреса та адресу проживання.

Вхід (Sign in): ця сторінка дозволяє користувачам увійти до свого облікового запису, ввівши електронну адресу та пароль. Також, користувач може створити акаунт, якщо його не існує, перейшовши по відповідному посиланню.

Реєстрація (Registration): на цій сторінці нові користувачі можуть створити обліковий запис, заповнивши необхідні поля. Для користувачів, які вже мають обліковий запис, надається посилання для переходу на сторінку входу.

Про застосунок (About): На цій сторінці надається коротка інформація про застосунок, його основні можливості, мету створення та автора.
